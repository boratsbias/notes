# T5: Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer (2020)

**Authors:** Colin Raffel et al.
**Area:** Natural Language Processing, Transfer Learning
**Link:** [arXiv](https://arxiv.org/abs/1910.10683)

## What the paper argues

The NLP field in 2019 had many task-specific architectures and training recipes. T5 argues for a unified framework: cast every NLP task as a text-to-text problem where both input and output are strings. This lets a single model architecture and training procedure be applied to everything, and enables systematic large-scale ablations of pre-training choices.

## The text-to-text framework

Every task is reformatted by prepending a task-specific prefix:

```
Summarization:    "summarize: {article}"              →  "{summary}"
Translation:      "translate English to German: {en}" →  "{de}"
Classification:   "sst2 sentence: {text}"             →  "positive" or "negative"
Question Answ.:   "question: {q} context: {c}"        →  "{answer}"
```

All tasks use the same encoder-decoder architecture (a standard transformer), the same cross-entropy loss, and the same fine-tuning procedure. Multi-task training mixes different tasks by sampling from a mixture of prefixed datasets.

## Span corruption pre-training

Rather than masking individual tokens (BERT's MLM), T5 masks contiguous spans and replaces each span with a single sentinel token:

```
Original:  "The cat sat on the mat in the park"
Corrupted: "The cat <X> the mat <Y> park"
Target:    "<X> sat on <Y> in the"
```

The model predicts only the masked spans, not the full sequence. This is more compute-efficient than BERT's MLM because fewer tokens need to be predicted per step.

## Ablation findings

T5 runs extensive ablations comparing pre-training objectives, model sizes, and dataset quality. Key findings:
- Span corruption > BERT-style MLM in compute efficiency
- More pre-training always helps, up to the largest scales tested
- C4 (cleaned Common Crawl) quality matters: unfiltered web text is significantly worse

## Results and impact

State of the art on GLUE, SuperGLUE, SQuAD, and CNN/DailyMail simultaneously. The text-to-text framing became highly influential and led directly to Flan-T5, mT5, and the instruction-following paradigm. T5's systematic ablation study is the standard reference for pre-training design decisions.
