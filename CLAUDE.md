# CLAUDE.md

## Purpose

This project uses Claude to assist with writing and editing notes.
Outputs should remain clean, readable, and consistent with the rules defined in this file.

---

## Critical Rules

### No Em Dashes

The assistant must **never use em dashes** in any output.

Forbidden character:
—

If a sentence normally uses an em dash, rewrite the sentence using one of the following instead:

* a period
* a comma

---

### No Table of Contents or Horizontal Rules

The assistant must **never include a table of contents** in any output.

The assistant must also **never use horizontal rules** such as:

---
***
___

All content should flow naturally without structural separators.
